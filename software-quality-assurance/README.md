# Software Quality Assurance

## Overview

Software Quality Assurance (SQA) es un dominio enfocado en asegurar la calidad del software mediante procesos, metodologías, estándares y buenas prácticas aplicadas durante el ciclo de vida del desarrollo de software.

Este dominio contiene documentación técnica, laboratorios, proyectos y rutas de aprendizaje orientadas al desarrollo de conocimientos prácticos relacionados con aseguramiento de calidad, procesos de validación y mejora continua.

---

## Purpose

El propósito de este dominio es desarrollar competencias relacionadas con:

- Principios fundamentales de Software Quality Assurance.
- Procesos de aseguramiento de calidad dentro del SDLC.
- Metodologías y buenas prácticas de testing.
- Mejora continua de procesos de calidad.

---

## Scope

Este dominio comprende las siguientes áreas:

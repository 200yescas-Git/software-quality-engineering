# Software Testing Masterclass - Esteban Balvin

## Overview

Esta ruta de aprendizaje está basada en el curso **Software Testing Desde Cero: Masterclass Todo en 1 con IA**, enfocado en desarrollar conocimientos fundamentales y prácticos sobre pruebas de software y aseguramiento de calidad.

El objetivo de esta ruta es construir una base sólida en Software Testing, comprendiendo metodologías, procesos, técnicas y herramientas utilizadas dentro de equipos profesionales de calidad de software.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Fundamentos de Software Testing.
- Procesos de Quality Assurance.
- Diseño y ejecución de pruebas.
- Identificación y gestión de defectos.
- Aplicación de buenas prácticas de calidad de software.
